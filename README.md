# pg-voicelab

**聲語匣**：瀏覽器語音合成（TTS）與語音識別（STT），可「回聲一句」。純前端，無建置步驟。

僅供作為 [Playgrounds（遊樂場）](https://samkuo.me/playgrounds/) 範本小品。依賴 Web Speech API——**不是**正式 ASR／TTS 雲服務；支援度與隱私邊界依瀏覽器而定（Chromium 系通常最完整）。
